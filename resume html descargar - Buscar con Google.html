    1. Encontrar una plantilla: Busca en sitios web como HTML Codex o W3Layouts una plantilla que se adapte a tus necesidades y estilo. 
    2. Descargar la plantilla: Una vez que hayas encontrado una plantilla que te guste, descarga el archivo HTML. 
    3. Abrir y editar: Abre el archivo HTML con un editor de código como Notepad++ o Visual Studio Code. 
    4. Personalizar: Modifica el contenido de la plantilla con tus propios datos y experiencia. 
    5. Guardar: Guarda el archivo con el nombre que quieras.
