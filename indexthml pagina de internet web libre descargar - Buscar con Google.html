    Para obtener el código HTML de una página web y descargarlo como "index.html" (o cualquier otro nombre), puedes usar las herramientas de desarrollo de tu navegador. La mayoría de los navegadores modernos, como Google Chrome y Firefox, permiten inspeccionar el código fuente de una página con un clic derecho y luego seleccionando "Ver el código fuente de la página" o similar. Una vez que hayas visto el código fuente, puedes copiar todo el código y guardarlo en un archivo con la extensión .html. 
    Pasos para descargar el código HTML de una página web:
    1. Abre la página web que quieres descargar. 
    2. Abre las herramientas de desarrollo del navegador. La mayoría de los navegadores lo hacen con un clic derecho en cualquier parte de la página y seleccionando "Ver el código fuente de la página" o una opción similar. También puedes usar atajos de teclado como Ctrl+U (en Windows) o Cmd+Option+U (en macOS). 
    3. Verás el código HTML. Este código es el que define la estructura de la página. 
    4. Selecciona todo el código HTML. 
    5. Copia el código. 
    6. Crea un nuevo archivo de texto en tu computadora. 
    7. Pega el código copiado en el archivo de texto. 
    8. Guarda el archivo con la extensión .html. Por ejemplo, guárdalo como "index.html" o cualquier nombre que prefieras.
